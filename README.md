# TOVMASYAN Jeweler — production-ready сайт для GitHub Pages

Премиальный статический сайт-витрина для бренда **TOVMASYAN Jeweler** в стиле черного мрамора, золота и бриллиантов.

## Что готово

- Главная страница `index.html`
- Большой каталог `catalog.html`
- 24 карточки изделий
- 24 отдельные страницы товаров в папке `products/`
- Страницы:
  - `custom.html` — индивидуальный заказ
  - `care.html` — уход и рекомендации
  - `about.html` — о бренде
  - `contacts.html` — контакты и заявка
- Фильтры каталога
- Поиск по каталогу
- Сортировка
- WhatsApp-заказы с готовым текстом сообщения
- Адаптивная мобильная версия
- SEO-структура, `robots.txt`, `sitemap.xml`, `404.html`
- Файл `products.csv` для удобного просмотра каталога
- Данные каталога в `data/products.js` и `data/products.json`

## Как запустить локально

```bash
python3 -m http.server 8000
```

Откройте:

```text
http://localhost:8000
```

## Как разместить на GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите все файлы из папки `tovmasyan-jeweler-site` в репозиторий.
3. Откройте **Settings → Pages**.
4. Выберите:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. Нажмите **Save**.
6. Через 1–3 минуты сайт будет доступен по ссылке GitHub Pages.

## Как менять товары

Основной файл каталога:

```text
data/products.js
```

Там можно изменить:

- название товара;
- категорию;
- материал;
- камни;
- описание;
- цену;
- фото;
- наличие.

Отдельные страницы товаров уже сгенерированы в папке `products/`.
